Projects I've Built

Secure Collaboration & Project Delivery

HandoffHub

A structured project handoff platform that helps developers and clients manage milestones, review deliverables, coordinate discussions, and securely share deployment credentials in a temporary workspace.

THE PROBLEM

Project requirements, progress updates, approvals, and deployment credentials are often scattered across multiple tools. HandoffHub brings these workflows into one workspace while protecting sensitive project data through end-to-end encryption.

ARCHITECTURE

A React-based frontend backed by Node.js and Express.js, with MongoDB for project metadata and Redis for temporary encrypted data storage. Socket.io enables real-time communication, while the Web Crypto API supports browser-side AES-256-GCM encryption and ECDH-based key exchange.

KEY FEATURES
  • Project overview, milestone tracking, and approval-based deliverable reviews
  • End-to-end encrypted credential sharing and real-time project discussions
  • Temporary project rooms with access-key verification and JWT-based session authentication

Application Security & Real-Time Collaboration

SafeHouse

An end-to-end encrypted temporary-room platform for sharing environment variables and exchanging messages in real time.

THE PROBLEM

Sharing API keys, database credentials, and environment files through ordinary messaging channels can expose sensitive configuration. SafeHouse provides temporary rooms with controlled access and client-side encryption.

ARCHITECTURE

A React frontend with a Node.js and Express backend, MongoDB persistence, and Socket.io for real-time room communication. The Web Crypto API handles ECDH P-256 key agreement and AES-256-GCM encryption on the client. JWT-based authentication protects authorized API operations.

KEY FEATURES
  • Temporary rooms for sharing environment variables and messages
  • ECDH P-256 key agreement and AES-256-GCM client-side encryption
  • JWT authentication and room-level access validation
  • Real-time chat and room activity using Socket.io
React Node.js Express.js MongoDB Socket.io JWT Web Crypto API ECDH P-256 AES-256-GCM
