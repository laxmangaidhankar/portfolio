Through these projects, I showcase my ability to build production-ready applications that are secure, scalable, and designed for real-world impact.

WHISPERSHARE

An account-less, one-time file-sharing platform that encrypts files in the browser before upload. It uses AES-256-GCM with HKDF-SHA-256 for client-side encryption and stores only encrypted file data in PostgreSQL (BYTEA), alongside the metadata needed to claim a share. Shares expire automatically, and atomic claim handling prevents repeated retrieval. The server never receives the plaintext file or encryption key.

React.js Node.js Express.js PostgreSQL AES-256-GCM Web Crypto API
